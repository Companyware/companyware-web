# Companyware Web release notes

Release notes are bound to one exact semantic version. The file name is
`<version>.md`; its first heading is `# Companyware Web <version>`.

Preparing a file here does not publish a release. Before tagging or publication,
review its scope, compatibility, security changes, known limitations, deployment
and recovery instructions against the exact release commit. The reproducible
archive builder records the file path and SHA-256 checksum in its evidence
manifest so published notes can be compared with the reviewed repository copy.
