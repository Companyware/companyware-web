# Companyware Web support

Companyware Web currently has no publicly supported stable release. The
`0.1.0-preview.1` candidate is a development preview without guaranteed response
or maintenance times.

## Compatibility target

| Component | Preview target |
| --- | --- |
| PHP | 8.3.x |
| Symfony | 6.4 LTS |
| Database | MySQL/MariaDB through Companyware migrations |
| Browsers | Current and previous stable Chrome, Edge, Firefox and Safari |
| Public PHP API | 1.0 |
| Administration SDK | 1.0 |

Use GitHub Issues for reproducible Companyware Web defects and bounded feature
proposals that contain no credentials, personal data or production exports. Use
the private process in `SECURITY.md` for suspected vulnerabilities.

Companyware Desktop has its own repository, runtime and release status. A Web
preview does not provide Desktop support.
